# Security Policy

This is a financial-infrastructure project. Vulnerabilities in matching, risk, or audit logic are treated as high priority.

## Reporting a Vulnerability

Please report security issues privately via GitHub's [Security Advisory](https://github.com/esam79rabba/matching-engine/security/advisories/new) form. Include a description of the issue, steps to reproduce, the affected commit or release, and the expected impact.

**Do not open public GitHub issues for security bugs.**

## Response Timeline

- Acknowledgement within 7 days of your report.
- Fix target within 90 days for critical issues.

## Supported Versions

| Version | Supported |
|---------|-----------|
| `main` branch | Yes |
| Latest release | Yes |
| Older releases | No |

## Scope

In scope: the engine daemon, the FIX gateway, the REST API, the portal, and the participant terminal.

Out of scope: test harness bugs and local development configuration issues.

## Credit

We credit reporters in release notes unless they ask to remain anonymous.
